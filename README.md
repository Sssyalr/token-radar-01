Token Radar ranks every protocol that records no token by what its token would be worth, and shows how to farm each one. Model radar-2 derives each category's multiple from the snapshot's own live-token protocols (median market-cap-to-TVL), then applies growth, maturity and chain-breadth multipliers — no protocol name is ever special-cased. The board covers all 40 watchlist protocols plus the clean pre-token protocols below the floor, 198 rows in all, with a seven-step farm plan per protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
