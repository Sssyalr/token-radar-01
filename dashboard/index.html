Token Radar

Every protocol that records no token, ranked by what its token would be worth if the record stayed as it is — and how to farm each one before it launches.

How the value is worked out

Implied value = TVL × the category multiple × growth × maturity × chain breadth. The multiple is not a guess: it is the median market-cap-to-TVL of the live-token protocols in the same category, read from this very snapshot. A category with too few live protocols falls back to the global median. No protocol name is ever special-cased.

The formula

  • Multiple — category median mcap / TVL (live tokens only), clamped 0.05–1.00
  • Growth — 1 + clamped 7-day TVL change (−60% to +120%) × 0.6
  • Maturity — 0.6 + age up to 3 years × 0.4 (unknown age: 1 year)
  • Breadth — 1 + 2% per extra chain, up to +10%
